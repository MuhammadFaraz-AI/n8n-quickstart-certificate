# n8n Quickstart, Completed Workflows and Certificate

This repo documents every workflow I built while completing n8n's official Quickstart program: n8n automation examples covering triggers, HTTP requests, data transformation, error handling, and a working AI agent built inside n8n.

Each folder below is one lesson from the course, with the exported workflow JSON and a README explaining what it does, which nodes it uses, and what it's meant to teach. This is meant to be useful for other people learning n8n, not just a proof of completion for me.

## What the program covers

n8n Quickstart is a hands-on n8n workflow automation course. It starts with the basics (triggers, scheduling, HTTP requests), moves into data transformation and error handling, and finishes with building a working AI agent in n8n that can look up real customer and order data to answer questions.
